# Week 7 Assignment: My Notes & The Report Builder

This repository contains my PLP Python Week 7 assignment.

- `my_notes.py`: Writes, appends, reads and counts notes.
- `my_notes.txt`: Stores the four notes created by the notes program.
- `report_builder.py`: Reads learner data from a CSV file and generates a report.
- `hubs.csv`: Contains learner names, hubs and scores.
- `report.txt`: Contains the generated learner report.

If I changed `"a"` to `"w"` in Question 1, the file would be opened in write mode instead of append mode. The fourth note would overwrite the existing notes rather than being added after them.
